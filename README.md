# From File to Closure: the interactive ladder

The 25-step ladder from the YouTube video "From File to Closure": what really happens when the
browser opens a 13-line JavaScript file. Parsing, execution contexts, Environment Records, the V8
Context, closures, the task queue, the event loop, rendering, garbage collection.

**Live version:** the link in this repository's About box.

**Controls:** → and ← (or the buttons) move one step; `n` hides or shows the explanations.

One file, no dependencies: you can also download `index.html` and open it in any browser.

Official names first, metaphors in parentheses. What the ECMAScript and WHATWG standards say is
kept apart from what is specific to V8.
